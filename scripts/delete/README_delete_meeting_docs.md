# 删除科技数智部会议文档脚本使用说明

## 脚本功能

该脚本用于查询并删除"科技数智部"知识库中所有包含"会议"关键词的文档。

## 主要特性

1. **自动查找目标知识库**：自动识别知识库名称中包含"科技数智部"的知识库
2. **关键词匹配**：查找文档名称中包含"会议"关键词的文档
3. **预览模式**：默认开启预览模式，只统计不删除，确保安全
4. **详细日志**：记录所有操作，包括成功和失败的详情
5. **错误处理**：失败的删除操作会被记录并显示

## 使用方法

### 1. 预览模式（默认，不会实际删除）

```bash
cd d:\1-item\55-环北自动化脚本\jioaben
python scripts/delete/delete_meeting_docs.py
```

预览模式下，脚本会：
- 查找所有匹配的文档
- 显示文档列表
- 统计将要删除的文档数量
- **不会执行实际删除操作**

### 2. 执行实际删除

如果预览结果符合预期，可以修改脚本执行实际删除：

1. 打开脚本文件 `scripts/delete/delete_meeting_docs.py`
2. 找到配置区域（第32-38行）
3. 将 `DRY_RUN = False` 改为 `DRY_RUN = False`
4. 保存文件
5. 重新运行脚本

```bash
python scripts/delete/delete_meeting_docs.py
```

## 配置选项

在脚本的配置区域，你可以自定义以下参数：

```python
# 目标知识库关键词（匹配知识库名称）
TARGET_DATASET_KEYWORD = "科技数智部"

# 文档名称关键词（匹配文档名称）
DOC_KEYWORDS = ["会议"]

# 删除间隔（秒）
DELETE_INTERVAL = 0.5

# 是否执行实际删除（False时只统计不删除，用于预览）
DRY_RUN = True
```

### 修改示例

如果你想查找更多关键词，可以修改 `DOC_KEYWORDS`：

```python
DOC_KEYWORDS = ["会议", "纪要", "记录"]
```

如果你想匹配其他知识库，可以修改 `TARGET_DATASET_KEYWORD`：

```python
TARGET_DATASET_KEYWORD = "其他部门名称"
```

## 安全提示

1. **务必先在预览模式下运行**，确认要删除的文档列表
2. 删除操作**不可逆**，请谨慎操作
3. 建议保存日志文件，以便后续查询
4. 如果有大量文档需要删除，建议分批次操作

## 故障排除

### 1. 找不到目标知识库

检查 `TARGET_DATASET_KEYWORD` 是否正确，确保知识库名称中包含该关键词。

### 2. 删除失败

- 检查网络连接
- 查看日志文件中的详细错误信息
- 确认有删除权限

### 3. 脚本运行报错

确保已安装所有依赖：

```bash
pip install -r requirements.txt
```
